# 🎀 ZAMALEK LEGENDS | أسطورة الزمالك

> **عالم كرتوني ممتع لتعلم تاريخ القلعة البيضاء — للأطفال والبنات وجميع الأعمار!**

لعبة ويب تفاعلية تعليمية وترفيهية عن نادي الزمالك، بالعربية بالكامل (RTL): **10 أقسام كرتونية** و**90 مرحلة × 20 سؤالًا** (1800 سؤال موثق)، مع 4 شخصيات كرتونية أصلية ترافق اللاعب، تلميحات لطيفة، صندوق مفاجآت، أوسمة أقسام، وشارات إنجاز — صممت لتجربة لعبة كاملة لا مجرد صفحة أسئلة.

---

## 💡 فكرة المشروع

لا مجرد اختبار أسئلة تقليدي، بل عالم كرتوني كامل:

- **عشرة أقسام مستقلة** في الصفحة الرئيسية على شكل بطاقات كرتونية: حكاية الزمالك، عالم كرة القدم، نجوم وأبطال، كنز البطولات، حكايات الجماهير، العبقري الصغير، تحدي الأبطال، أبطال الألعاب الأخرى، عالم الصغار، وتحدي الصور.
- **90 مرحلة × 20 سؤالًا**، تُفتح تدريجيًا داخل كل قسم، وكل مرحلة بأسلوب حواري مرح كأن شخصية كرتونية تتكلم مع الطفل.
- **4 شخصيات أصلية برسوم SVG**: زملكاوي الصغير، زملكاوية الصغيرة (التلميحات)، الكابتن، والحكيم الأبيض (المعلومات التاريخية).
- **14 نوعًا من الأسئلة**: اختيار متعدد، صح/خطأ، أكمل الجملة، اختر الصورة، من أنا؟، رتب الأحداث، خمّن الرمز، اكتشف المعلومة الصحيحة، تحدي السرعة، صِل المعلومة بإجابتها، في أي عام، خمّن اللاعب، خمّن البطولة، وسؤال حسم بنقاط مضاعفة.
- **نظام مكافآت محبب**: نقاط خبرة (XP)، نجوم (1-3 لكل مرحلة)، ميداليات، وسام خاص لكل قسم، 20 شارة إنجاز، وصندوق مفاجآت بعد المراحل الناجحة.
- **موسوعة الزمالك**: بطاقات معرفية قابلة للبحث والتصفية — مصدر التعلم قبل التحدي.
- **صفحات للاعب**: ملف شخصي ببطاقة البطل، مفضلة لحفظ المعلومات الجميلة، دليل مساعدة، وصفحة جوائز.
- **حفظ تلقائي آمن**: التقدم كله على جهاز اللاعب (LocalStorage) بلا أي بيانات شخصية، مع استكمال من آخر نقطة توقف ومهاجرة آمنة للحفظ القديم.

### 📚 مصادر المعلومات

جميع الحقائق التاريخية موثقة من مصادر موثوقة، مع الفصل بين **الأرقام التاريخية الثابتة** (مثل سنوات التأسيس والأسماء) و**الإحصائيات المتغيرة** (مثل أعداد الألقاب — مثبتة حتى نوفمبر 2026):

- ويكيبيديا العربية — [مقال نادي الزمالك](https://ar.wikipedia.org/wiki/نادي_الزمالك) (المصدر الأساسي)
- ويكيبيديا الإنجليزية — مقال Zamalek SC (جداول الألقاب والسنين)
- الموقع الرسمي للاتحاد الإفريقي لكرة القدم (كاف) — تفاصيل كأس السوبر الإفريقي 2024
- تقارير رياضية موثوقة (FilGoal، Youm7، الجزيرة، العربية) للنتائج التاريخية

> ⚠️ هذه لعبة جماهيرية تعليمية **غير رسمية** وليست تابعة لنادي الزمالك. الرسوم والأصوات كلها أصلية مولّدة خصيصًا للعبة (لا صور محمية بحقوق).

## 🚀 طريقة التشغيل محليًا

اللعبة مبنية بـ **HTML5 + CSS3 + JavaScript Vanilla خالص** (ES Modules) بلا أي أدوات بناء.

### الطريقة 1: أي خادم ثابت بسيط

```bash
# انتقل إلى مجلد اللعبة
cd zamalek-legends

# مع Python
python3 -m http.server 8080

# أو مع Node.js
npx serve .
```

ثم افتح المتصفح على: `http://localhost:8080`

### الطريقة 2: VS Code Live Server
ثبّت إضافة *Live Server* ثم اضغط «Go Live» على `index.html`.

> **مهم:** بسبب سياسة ES Modules يجب فتح اللعبة عبر خادم محلي، وليس بفتح `index.html` مباشرة (بروتوكول `file://`).

## ➕ طريقة إضافة مرحلة جديدة (دون تعديل محرك اللعبة)

1. أنشئ ملفًا داخل مجلد القسم، مثل `js/sections/history/stage-91.js` (20 سؤالًا):

```js
const stage = {
  id: 91,
  title: 'عنوان مرحلتك',
  description: 'وصف مرح قصير',
  difficulty: 'medium',        // easy | medium | hard | legend
  points: 120,

  questions: [
    {
      id: 1,
      type: 'multiple',        // أنواع مدعومة (انظر أدناه)
      question: 'يلا يا بطل! نص السؤال الممتع؟ ⚽',
      options: ['أ', 'ب', 'ج', 'د'],
      answer: 'ب',             // يطابق نص أحد الاختيارات
      hint: 'تلميح لطيف يظهر عند الضغط على زر 💡',
      explanation: 'معلومة لطيفة تظهر بعد الإجابة حتى يتعلم الطفل.'
    }
  ]
};

export default stage;
```

2. سجّل سطرًا في `NEW_STAGE_METAS` داخل `js/sections-manager.js`:

```js
{ id: 91, title: 'عنوان مرحلتك', subtitle: 'وصف قصير', icon: '🆕',
  difficulty: 'medium', points: 120 },
```

3. أضف رقم المرحلة إلى قائمة `stages` في القسم المناسب داخل `SECTIONS`، ومسارها في `REGISTRY` بنفس الملف:
   `91: './sections/history/stage-91.js',`

هذا كل شيء — بطاقة القسم والفتح التدريجي والمحرك والإحصائيات ستتعرف عليه تلقائيًا.

لإضافة **قسم جديد** بالكامل: أنشئ مجلده في `js/sections/` وأضف كائنًا إلى `SECTIONS` (العنوان، الإيموجي، الألوان، الشخصية المرافقة، قائمة المراحل).

## 📝 أنواع الأسئلة المدعومة (14)

| النوع | الحقل `type` | حقول إضافية |
|---|---|---|
| اختيار من متعدد | `multiple` | `options`, `answer` (نص) |
| صح أم خطأ | `truefalse` | `answer: 'صح'` أو `'خطأ'` |
| أكمل الجملة | `complete` | كالمتعدد مع «____» في السؤال |
| في أي عام | `year` | كالمتعدد |
| من أنا؟ | `whoami` | كالمتعدد (يُفضل مع `hint`) |
| خمّن اللاعب | `guessplayer` | كالمتعدد |
| خمّن البطولة | `guesstrophy` | كالمتعدد |
| سؤال بالصورة | `image` | `image: 'emblem'` أو `'kit_white'` أو مفاتيح الرسوم الأصلية |
| اختر الصورة الصحيحة | `imagepick` | `images: [4 مفاتيح]`, `answer` (مفتاح) |
| خمّن الرمز | `logo` | `logo` (مفتاح رسم يعرض كبيرًا) + `options`, `answer` |
| اكتشف المعلومة الصحيحة | `pickinfo` | كالمتعدد (عبارات كاملة كبطاقات) |
| صِل المعلومة بإجابتها | `match` | `pairs: [[معلومة، إجابة] × 3]` |
| تحدي السرعة | `speed` | `time: 12` (خصم نقاط عند الخطأ) |
| ترتيب الأحداث | `order` | `items: [...]` **بالترتيب الصحيح** (يُخلط تلقائيًا) |
| سؤال الحسم | أي نوع + `decisive: true` | نقاط مضاعفة (يُفضل آخر سؤال) |

**مفاتيح الرسوم الأصلية المتاحة** (SVG مرسومة خصيصًا للعبة): `ball, castle, shield, trophy, star, whistle, goal, glove, scarf, medal, heart, basket, handball, volley, flag, emblem, kit_white, kit_red, kit_green, kit_blue`.
كل سؤال يُفضل أن يحمل `hint` لطيفًا (زر 💡 يظهر للطفل عند الحاجة).

## 💾 كيف يحفظ النظام تقدم اللاعبين؟

كل شيء يُخزّن محليًا في متصفح اللاعب بمفتاح `zamalek_legends_save_v1` (LocalStorage) — **بلا أي بيانات شخصية للأطفال**:

- لقب العرض (اختياري)، الشخصية الكرتونية المختارة، نقاط الخبرة، الإجابات الصحيحة/الخاطئة.
- المراحل المكتملة ونجومها وأفضل النتائج (الفتح التدريجي يُحسب تلقائيًا من الأقسام).
- الشارات المفتوحة، المعلومات المحفوظة في المفضلة، صناديق المفاجآت المفتوحة.
- بطاقات الموسوعة المقروءة، إعدادات الصوت والوضع الليلي.

حفظ اللعبة القديم (قبل التحديث إلى عالم الأقسام) **يُهاجَر تلقائيًا** دون فقدان أي تقدم، وعند فتح اللعبة مرة أخرى يعود اللاعب لآخر نقطة، ويمكنه إعادة الضبط من الإعدادات (مع رسالة تأكيد).

## 🛠️ ملاحظات تقنية

- **HTML5 + CSS3 + Vanilla JS** فقط — بلا React/Vue/Angular وبلا أدوات بناء.
- ES Modules (`type="module"`) مع **Dynamic Import**: تُحمّل أسئلة المرحلة المطلوبة فقط عند دخولها.
- معالجة أخطاء تحميل المراحل بشاشة خطأ واضحة وزر عودة.
- تصميم متجاوب بالكامل (هواتف + أجهزة لوحية + كمبيوتر) ولمسات داعمة للوصولية (ARIA).
- الوضع الليلي والصوت محفوظان في التقدم.
- الأصوات ملفات WAV أصلية مولّدة برمجيًا، والرسوم SVG أصلية — لا توجد أصول محمية بحقوق.

> **تحديث الإحصائيات:** أعداد الألقاب في الأسئلة والموسوعة مثبتة وفق المصادر حتى **نوفمبر 2026**. عند فوز الزمالك بألقاب جديدة، حدّث الأرقام في ملفات المراحل وبطاقات الموسوعة (البطاقات المحددة بعبارة «حتى نوفمبر 2026»).
