# 🏹 أسطورة الزمالك | ZAMALEK LEGENDS

> **التاريخ يُحكى... والأساطير لا تُنسى.**

لعبة ويب تفاعلية عربية بالكامل (RTL) لمحبي نادي الزمالك المصري — رحلة مغامرة من تأسيس النادي عام 1911 حتى العصر الحديث، عبر **20 مرحلة تاريخية** وموسوعة موثقة ونظام نقاط وإنجازات.

---

## 💡 فكرة المشروع

لا مجرد اختبار أسئلة تقليدي، بل تجربة مغامرة كاملة:

- **خريطة مراحل** تُفتح تدريجيًا عبر الزمن: من «البدايات البيضاء» 1911 إلى «الاختبار الأسطوري».
- **11 نوعًا من التحديات**: اختيار متعدد، صح/خطأ، أكمل المعلومة، ترتيب الأحداث زمنيًا، من صاحب الإنجاز، في أي عام، خمّن اللاعب، خمّن البطولة، أسئلة بالصور، تحدي سرعة، وسؤال حسم بنقاط مضاعفة.
- **موسوعة الزمالك**: 30 بطاقة معرفية قابلة للبحث والتصفية — مصدر التعلم قبل التحدي.
- **نظام تقدم متكامل**: نقاط، نجوم (1-3 لكل مرحلة)، 12 شارة إنجاز، و5 مستويات للاعب: من «مشجع جديد» إلى «أسطورة الزمالك».
- **حفظ تلقائي**: تقدمك ينتظرك في نفس المكان عند العودة.

### 📚 مصادر المعلومات

جميع الحقائق التاريخية موثقة من مصادر موثوقة، مع الفصل بين **الأرقام التاريخية الثابتة** (مثل سنوات التأسيس والأسماء) و**الإحصائيات المتغيرة** (مثل أعداد الألقاب — مثبتة حتى نوفمبر 2026):

- ويكيبيديا العربية — [مقال نادي الزمالك](https://ar.wikipedia.org/wiki/نادي_الزمالك) (المصدر الأساسي)
- ويكيبيديا الإنجليزية — مقال Zamalek SC (جداول الألقاب والسنين)
- الموقع الرسمي للاتحاد الإفريقي لكرة القدم (كاف) — تفاصيل كأس السوبر الإفريقي 2024
- تقارير رياضية موثوقة (FilGoal، Youm7، الجزيرة، العربية) للنتائج التاريخية

> ⚠️ هذه لعبة جماهيرية تعليمية **غير رسمية** وليست تابعة لنادي الزمالك. الرسوم والأصوات كلها أصلية مولّدة خصيصًا للعبة (لا صور محمية بحقوق).

## 🚀 طريقة التشغيل محليًا

اللعبة مبنية بـ **HTML5 + CSS3 + JavaScript Vanilla خالص** (ES Modules) بلا أي أدوات بناء.

### الطريقة 1: أي خادم ثابت بسيط

```bash
# انتقل إلى مجلد اللعبة
cd zamalek-legends

# مع Python
python3 -m http.server 8080

# أو مع Node.js
npx serve .
```

ثم افتح المتصفح على: `http://localhost:8080`

### الطريقة 2: VS Code Live Server
ثبّت إضافة *Live Server* ثم اضغط «Go Live» على `index.html`.

> **مهم:** بسبب سياسة ES Modules يجب فتح اللعبة عبر خادم محلي، وليس بفتح `index.html` مباشرة (بروتوكول `file://`).

## ➕ طريقة إضافة مرحلة جديدة (دون تعديل محرك اللعبة)

1. أنشئ ملفًا جديدًا `js/stages/stage-21.js`:

```js
const stage = {
  id: 21,
  title: 'عنوان مرحلتك',
  description: 'وصف تاريخي قصير',
  difficulty: 'medium',        // easy | medium | hard | legend
  points: 120,

  questions: [
    {
      id: 1,
      type: 'multiple',        // أنواع مدعومة (انظر أدناه)
      question: 'نص السؤال؟',
      options: ['أ', 'ب', 'ج', 'د'],
      answer: 'ب',             // يطابق نص أحد الاختيارات
      explanation: 'التفسير التاريخي الذي يظهر بعد الإجابة.'
    }
  ]
};

export default stage;
```

2. سجّل سطرًا واحدًا في الفهرس المركزي داخل `js/stages-manager.js`:

```js
{ id: 21, title: 'عنوان مرحلتك', subtitle: 'وصف قصير', icon: '🆕',
  difficulty: 'medium', points: 120, theme: 'linear-gradient(135deg,#aaa,#555)' },
```

3. أضف مسار الملف إلى `REGISTRY` بنفس الملف: `21: './stages/stage-21.js',`

هذا كل شيء — الخريطة والمحرك والإحصائيات ستتعرف عليه تلقائيًا.

## 📝 أنواع الأسئلة المدعومة

| النوع | الحقل `type` | حقول إضافية |
|---|---|---|
| اختيار من متعدد | `multiple` | `options`, `answer` (نص) |
| صح أم خطأ | `truefalse` | `answer: 'صح'` أو `'خطأ'` |
| أكمل المعلومة | `complete` | كالمتعدد مع «____» في السؤال |
| في أي عام | `year` | كالمتعدد |
| من صاحب الإنجاز | `whoami` | كالمتعدد |
| خمّن اللاعب | `guessplayer` | كالمتعدد |
| خمّن البطولة | `guesstrophy` | كالمتعدد |
| سؤال بالصورة | `image` | `image: 'emblem'` أو `'kit_white'` |
| تحدي السرعة | `speed` | `time: 12` (خصم نقاط عند الخطأ) |
| سؤال الحسم | أي نوع + `decisive: true` | نقاط مضاعفة (يُفضل آخر سؤال) |
| ترتيب الأحداث | `order` | `items: [...]` **بالترتيب الصحيح** (يُخلط تلقائيًا) |

## 💾 كيف يحفظ النظام تقدم اللاعبين؟

كل شيء يُخزّن محليًا في متصفح اللاعب بمفتاح `zamalek_legends_save_v1` (LocalStorage):

- اسم اللاعب، إجمالي النقاط، الإجابات الصحيحة/الخاطئة.
- المراحل المفتوحة والمكتملة، نجوم كل مرحلة، أفضل نتيجة.
- الشارات المفتوحة، بطاقات الموسوعة المقروءة.
- إعدادات الصوت والوضع الليلي.

عند فتح اللعبة مرة أخرى يعود اللاعب تلقائيًا لآخر تقدم، ويمكنه إعادة الضبط من الإعدادات (مع رسالة تأكيد).

## 🌐 النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub وارفع مجلد `zamalek-legends/` كاملًا (يمكن أن يكون في جذر المستودع أو في مجلد فرعي — كل المسارات نسبية).
2. من **Settings → Pages** اختر المصدر: الفرع `main` والمجلد `/ (root)` (أو `/docs` إن رفعت اللعبة داخله).
3. خلال دقائق ستكون اللعبة متاحة على: `https://<username>.github.io/<repo>/`

> ✅ كل المسارات نسبية (`./css/...`, `./js/...`) والراوتر قائم على الهاش (`#/stages`) — لا حاجة لأي إعداد خادم، ولا توجد قاعدة بيانات أو Backend.

## 🛠️ ملاحظات تقنية

- **HTML5 + CSS3 + Vanilla JS** فقط — بلا React/Vue/Angular وبلا أدوات بناء.
- ES Modules (`type="module"`) مع **Dynamic Import**: تُحمّل أسئلة المرحلة المطلوبة فقط عند دخولها.
- معالجة أخطاء تحميل المراحل بشاشة خطأ واضحة وزر عودة.
- تصميم متجاوب بالكامل (هواتف + أجهزة لوحية + كمبيوتر) ولمسات داعمة للوصولية (ARIA).
- الوضع الليلي والصوت محفوظان في التقدم.
- الأصوات ملفات WAV أصلية مولّدة برمجيًا، والرسوم SVG أصلية — لا توجد أصول محمية بحقوق.

> **تحديث الإحصائيات:** أعداد الألقاب في الأسئلة والموسوعة مثبتة وفق المصادر حتى **نوفمبر 2026**. عند فوز الزمالك بألقاب جديدة، حدّث الأرقام في ملفات المراحل وبطاقات الموسوعة (البطاقات المحددة بعبارة «حتى نوفمبر 2026»).
